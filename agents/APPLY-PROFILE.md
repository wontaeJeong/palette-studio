# OpenCode 작업지시 · 선택 프로필 적용

Superpowers는 이미 활성화한 상태입니다. 첨부한 `design-profile.json`과 `selected-theme.css`를 기준으로 앱 UI를 적용해 주세요. 키트 경로는 `design/palette-studio/`입니다.

`agents/DESIGN-CONTRACT.md`를 따르되 기존 앱의 UI 컴포넌트·CSS 선택자·테마·폰트 로더를 재사용하세요. 키트 foundation은 사용 예제이며 기존 UI를 대체하라는 요구가 아닙니다. 이미 활성화된 Superpowers의 일반 탐색·구현 절차는 중복할 필요 없습니다.

화면에서 맞춰야 할 기준은 다음과 같습니다.

- 선택 palette·style·scope를 유지합니다. dark-only면 라이트 색상은 바꾸지 않습니다.
- 사이드바는 차분한 shell, 현재 메뉴는 약한 포인트 면과 좌측 표시. 탭은 밑줄 중심으로 구분합니다.
- 본문과 보조 정보는 ink/ink-muted로 계층을 만들고 주요 CTA와 선택만 accent로 강조합니다.
- 입력은 line-strong 수준 경계와 명확한 focus, 오류는 설명 문구와 기호를 함께 제공합니다.
- 표는 긴 이름·여러 상태·선택 행·hover가 동시에 있어도 읽히도록 합니다. 색상 변경 때문에 데이터 밀도를 불필요하게 낮추지 않습니다.
- 코드와 JSON은 fill+border, 타입별 색상, 긴 줄 스크롤·복사 동작을 유지합니다.
- 상태색과 심각도는 브랜드 포인트와 별개입니다. 보류/실행 오류를 혼동시키지 않습니다.

테마 정의는 기존 canonical 위치에 병합하고 var() 색상 별칭을 추가하지 마세요. 앱의 기존 대비 검증에는 변경된 쌍을 반영합니다. 키트의 정적 검사와 실제 앱의 화면·동작 검증 결과를 구분해 남기고, 선택한 디자인을 이후 화면에도 유지할 수 있게 짧은 결정 기록을 작성하세요.
