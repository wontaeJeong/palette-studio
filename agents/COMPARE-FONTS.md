# OpenCode 작업지시 · 폰트 선택과 적용

Superpowers는 이미 활성화된 상태입니다. `design/palette-studio/`의 폰트 카탈로그와 선택 프로필을 UI에 활용해 주세요.

색상·레이아웃·글자 크기를 고정한 상태에서 실제 대표 화면으로 폰트를 비교합니다. 한글 UI는 Pretendard / SUIT / Wanted Sans / IBM Plex Sans KR 중 2~3개, 코드는 D2Coding과 선택한 영문 고정폭 폰트를 출발점으로 삼으세요. 영문 전용 후보에는 프로필에 지정된 한글 보완 폰트를 유지합니다.

- 사이드바의 긴 한국어, 표의 저장소명·숫자·날짜·상태 배지, 폼의 placeholder를 같이 봅니다.
- JSON과 로그에서는 한글 주석, `0O 1lI ①②`, 특수문자·한글 폭과 fallback 혼용을 확인합니다.
- 같은 화면에서 normal / semibold / bold의 가독성과 행 높이, 줄바꿈 차이를 확인합니다. 선택하지 않은 굵기를 임의로 합성해 비교하지 않습니다.
- CDN 우선 / 외부 차단 / 로컬 전용에서 UI를 계속 사용할 수 있는지 확인합니다. 기존 로더를 재사용하고 중복 설치하지 않습니다.
- 동봉 폰트는 `data/fonts.json`의 고정 버전·해시를 기준으로 사용하고 해당 저작권·OFL 파일을 유지합니다. 개인·비상업 전용 무료 폰트나 라이선스가 불명확한 다른 폰트를 섞지 않습니다.

선택 결과는 `design-profile.json`의 fonts와 결정 기록에 남깁니다. ‘다크만 변경’은 컬러 범위이고 폰트 설정은 두 컬러 모드에 공통입니다. 폰트를 정한 뒤에는 새 화면마다 임의로 바꾸지 마세요.
