## UI 디자인 기준

선택된 `design/design-profile.json`을 UI 기준으로 사용한다. 관련 작업에서는 `design/palette-studio/agents/DESIGN-CONTRACT.md`와 `design/palette-studio/docs/INTEGRATION.md`를 읽는다. 팔레트·스타일·변경 범위를 유지하고 기존 컴포넌트를 재사용한다. dark-only면 라이트 색상을 보존한다. 색 토큰 선언은 직접 HEX, 컴포넌트는 의미 토큰으로 소비한다. 상태색과 심각도 의미를 유지한다. 새 화면도 같은 규칙을 따른다.
