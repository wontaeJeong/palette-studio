## 추천 조합

- Gate 기본 · Pretendard + D2Coding
- 중립 제품 · SUIT + D2Coding
- 기하학적 UI · Wanted + Geist Mono
- 기업용 도구 · IBM Plex Sans KR + IBM Plex Mono
- 문서 포털 · Noto Sans KR + Source Code Pro
- 한국어 읽기 · Noto Serif KR + D2Coding
- 영문 SaaS · Inter + JetBrains Mono
- 영문 개발 도구 · Geist + Geist Mono

Variable의 굵기 범위와 정적 400/700은 구분합니다. `package`는 CDN 패키지 버전이며 원본 폰트의 버전 번호와 다를 수 있습니다. 파일별 정확한 URL·SHA256·unicode-range는 `data/fonts.json`에 있습니다.


한글 UI는 Pretendard·SUIT·Wanted Sans·IBM Plex Sans KR부터 비교하고, 장문에는 Noto Serif KR도 비교해 보세요. 영문 중심의 Inter·Geist 등은 한국어 본문을 대체하는 폰트가 아니라 선택한 영문과 한글 보완 폰트의 조합입니다.
