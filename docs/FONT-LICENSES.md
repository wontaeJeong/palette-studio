# 폰트 라이선스 확인표

확인일: 2026-10-27. 동봉한 24개 폰트는 원본 라이선스 전문을 확인한 SIL OFL 1.1 배포본입니다. 사내 업무·상업용 디자인·웹폰트 사용과 앱 동봉이 허용됩니다. 원본 저작권·OFL 고지를 함께 유지합니다. 폰트 자체의 단독 판매와 라이선스 변경은 허용하지 않으며, 수정 배포에는 Reserved Font Name 조건이 적용될 수 있습니다. 이 패키지는 원본 WOFF2를 변경하지 않았습니다.

앱에 동봉해도 앱 전체를 OFL로 공개할 의무는 없습니다. 폰트 라이선스는 폰트에 유지됩니다. 공식 기준: https://openfontlicense.org/how-to-use-ofl-fonts/ 및 https://openfontlicense.org/ofl-faq/ .
