# 공식 참고 자료

2026-10-27 확인. 이 패키지의 새 색상 조합·스타일은 자체 작성안입니다. 다음 문서는 기술적 사용 기준의 참고 자료입니다.

- W3C WCAG 2.2, Contrast (Minimum): https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html — 일반 텍스트 4.5:1, 큰 텍스트 예외. 키트는 작은 텍스트를 포함해 선언된 텍스트 쌍에 4.5:1을 사용합니다.
- W3C WCAG 2.2, Non-text Contrast: https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html — 의미 있는 UI 식별 요소와 그래픽의 대비. 장식용 모든 선을 일괄 적용 대상으로 보지 않습니다.
- W3C WCAG 2.2, Focus Appearance: https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html — focus appearance는 AAA 기준입니다. 이 키트의 포커스 수치만으로 AAA 준수를 주장하지 않습니다.
- Tailwind CSS, Adding custom styles: https://tailwindcss.com/docs/adding-custom-styles — @utility와 상태 variant.
- Tailwind CSS, Functions and directives: https://tailwindcss.com/docs/functions-and-directives — @utility 지시문.
- OpenCode, Rules: https://opencode.ai/docs/rules/ — AGENTS.md와 instructions 파일 참조. 설정 예시는 기존 설정에 병합하는 용도입니다.

원문을 대량 인용하지 않고 필요한 기준을 요약했습니다. 프로젝트별 접근성·프레임워크 동작은 실제 버전과 사용 문맥에서 검증하세요.
