# 의미 토큰과 클래스

각 팔레트는 아래 모든 토큰을 두 모드에 제공합니다. `cp-bg-*`는 background-color, `cp-text-*`는 color, `cp-border-*`는 border-color, `cp-fill-*`/`cp-stroke-*`는 SVG 속성입니다. 경계선 너비·스타일은 별도로 지정하세요.

모든 토큰에 5종 클래스가 있지만 아무 전경·배경이나 조합해도 된다는 뜻은 아닙니다. 허용된 사용 쌍과 대비 기준은 `data/contrast-pairs.json`, 실제 값은 `data/tokens.csv`를 확인하세요. 아래는 클래스 재고 목록입니다.
