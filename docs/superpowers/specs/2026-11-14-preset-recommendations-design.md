# 프리셋 추천 표시

사용자가 디자인 세트를 고른 뒤 컴포넌트 표현, 메뉴 배치·구성·선택 표시, 전환 속도에서 추천을 바로 확인한다. 사용자는 권장 방향으로 구현하고 머지하는 것을 승인했으며 추가 시안·질문을 생략하도록 요청했다.

## 접근 방식
기존 옵션 옆에 레이블을 붙이는 방식을 채택한다. 별도 추천 요약 패널은 옵션을 확인하려면 다시 이동해야 하고, 추천 옵션만 숨김 없이 남기는 필터는 다른 디자인과 비교하기 어렵다.

## 동작과 범위
- `PaletteDesignCatalog.selection(setId)`의 기본값을 추천 기준으로 사용한다. 별도 추천 데이터나 저장 필드를 만들지 않는다.
- 컴포넌트 상세의 디자인 옵션과 메뉴 선택 표시 카드에는 `프리셋 추천`과 `선택됨`을 각각 표시한다. 추천과 선택이 같으면 둘 다 표시한다.
- 메뉴 배치·구성·전환 속도는 기존 native select를 유지하며 추천 option에 ` · 프리셋 추천`을 붙인다. 필드 아래에도 추천값을 보여 드롭다운을 열기 전에 확인할 수 있게 한다.
- 컴포넌트 목록에 현재 디자인과 프리셋 추천 디자인을 함께 표시한다. 기존 컴포넌트 자체의 권장 배지는 `권장 요소`로 구분한다.
- 개별 변경과 팔레트 변경은 추천 기준을 바꾸지 않는다. 프리셋 변경 시 기준을 갱신하고 기존 선택 초기화 동작을 유지한다.
- 새로고침·공유 링크 복원 후에도 저장한 실제 선택과 해당 프리셋의 추천을 각각 표시한다. 내보내기에는 실제 선택을 유지한다.
- 기존 레이아웃, 폰트, 팔레트, 상태 색상 및 내보내기 계약을 재사용한다. 색상만으로 상태를 표현하지 않고 키보드 포커스를 유지한다.
- 웹과 단일 파일 `START-HERE.html`에 동일하게 반영한다.

## 검증
브라우저에서 6개 프리셋의 대표 추천, 기본값/예외값, 개별 수정 후 추천 유지, 공유/새로고침, 모바일과 두 테마를 확인한다. 기존 흐름 및 내보내기 검사와 생성물·스크린샷 최신성 검사를 실행한다.

## 추가 요청: 오버레이 즉시 미리보기
사용자는 팝업과 다이얼로그도 버튼 없이 바로 보이도록 요청했다. 상세 화면에서 다이얼로그·드로어·토스트를 인라인 견본으로 항상 표시하고, 툴팁과 팝업 메뉴도 처음부터 펼친다. 전체 화면 모달을 자동으로 열지는 않는다. 추가 동작 확인 버튼은 견본 아래에 유지한다. 라이트·다크와 표현 변경이 견본에 반영되고, 버튼으로 띄운 실제 데모를 닫아도 견본은 남는다. 공유 렌더러를 사용하는 `catalog.html`에도 반영한다.
