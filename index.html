선택한 설정을 실제 앱에 적용하고 동일한 화면·데이터로 비교합니다.

01 / EXPLORE

색상과 스타일을 따로 선택

먼저 포인트와 바탕을 고르고, 다음에 라운드·여백·정보 밀도를 고릅니다. 색상과 스타일은 독립적으로 변경할 수 있습니다.

02 / COMPARE

실제 앱의 같은 화면에 적용

일반 목록, 긴 상세, 실패·권한 없음 화면을 같은 데이터로 비교합니다. 샘플은 미리보기용 데이터입니다. 실제 앱 컴포넌트의 검증을 대신하지 않습니다.

03 / COMMIT

프로필을 저장하고 기준 고정

내보낸 JSON과 CSS를 저장소에 넣고 작업지시를 전달합니다. 기존 테마 정의에 병합해 중복을 없애고, 선택 범위 안에서만 색상을 바꿉니다.
