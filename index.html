글자의 분위기도, 직접 선택.

사내·상업용 사용이 허용되는 OFL 폰트 24종. 한글 지원과 용도를 확인하고 같은 문장으로 비교하세요.

동봉·웹폰트 재배포에는 원래 저작권과 OFL 고지를 유지합니다. 폰트 파일 단독 판매·라이선스 변경은 허용하지 않으며, 수정 배포 시 Reserved Font Name 조건을 따릅니다. 아래 견본은 화면에 보이는 카드부터 필요한 글리프를 읽습니다.

버튼부터 오류 상태까지.

같은 의미를 유지하는 상태색, 키보드 포커스, 폼 검증, JSON 하이라이트. 버튼의 hover·pressed·focus 상태는 비교용 고정 샘플입니다.

색상의 이름보다, 쓰임새.

테마마다 같은 189개 의미 토큰을 제공합니다. 색상 셀을 누르면 HEX를 복사합니다.

01 / EXPLORE

색상과 스타일을 따로 선택

먼저 포인트와 바탕을 고르고, 다음에 라운드·여백·정보 밀도를 고릅니다. 모든 요소를 한 번에 바꾸면 무엇이 좋아졌는지 판단하기 어렵습니다.

02 / COMPARE

실제 앱의 같은 화면에 적용

일반 목록, 긴 상세, 실패·권한 없음 화면을 같은 데이터로 비교합니다. 이곳의 샘플은 출발점입니다. 실제 Admission Gate 컴포넌트의 검증을 대신하지 않습니다.

03 / COMMIT

프로필을 저장하고 기준 고정

내보낸 JSON과 CSS를 저장소에 넣고 작업지시를 전달합니다. 기존 테마 정의에 병합해 중복을 없애고, 선택 범위 안에서만 색상을 바꿉니다.
